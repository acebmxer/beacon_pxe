Storage drivers for Windows Setup. Stock Windows 11 WinPE has no driver for Intel VMD / RST or AMD RAID, so on most laptops from Intel's 11th gen onward Setup reaches “Where do you want to install Windows?” with an empty disk list. Drop the vendor's F6 / pre-install driver package here and Beacon hands it to Setup through an answer file as it starts — PnP-matched, so the disk appears in the installer and the finished OS keeps booting. Applies to every Windows image, from the next boot — no reprocessing needed.

Add drivers

Upload the vendor's .zip, or select the loose .inf / .sys / .cat files of an already-extracted package.
Uploading…
Pick the kind that matches the driver. Storage packs go on the SMB share — live on the next boot, no re-baking, but useless for a NIC (they sit on the far side of the network the NIC can't reach). Network packs are baked into every Windows image's boot.wim and loaded before networking starts; adding one re-bakes the boot images automatically.
Mixing vendors is safe — Setup PnP-matches, so only the driver for hardware actually present is installed.
